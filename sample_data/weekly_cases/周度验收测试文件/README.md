# 周度功能验收样例

业务月份209901，平台jd，国家选择中国，品类耳机。商品名称包含“周度验收”，ID以WEEKLY-ACCEPT-开头。

按01→02→03等编号使用。01、02、03选择周度并从文件周列读取；04选择月度；05选择周度并手动指定第3周；06、07从已有第2周任务的“补充数据”上传。

- 01写入5条，分别为第1～5周。
- 02写入0条、跳过5条。
- 03写入1条、跳过1条，分发后追加到第2周原任务。
- 04写入1条独立月度数据。
- 05写入1条第3周数据。
- 06继承第2周任务，新增1条、跳过1条。
- 07周次与目标第2周任务冲突，不能入库。
- invalid目录的全部文件都应提示周次问题。
- 08、09为可选用例，会额外增加测试数据。

主流程完成后：周度8条（各周1、3、2、1、1），月度1条。

完整操作、发布及导出预期见项目docs目录的《周度功能测试文档-2026-11-27.md》。在正式测试环境需先配置可命中“周度验收”标题的耳机分发规则；本地预览环境已预置规则。
