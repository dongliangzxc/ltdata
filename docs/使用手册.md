## 2. 整体工作流程

平台的核心处理链路如下，建议按顺序操作：

```
准备工作（一次性）          每批数据处理流程
─────────────────          ──────────────────────────────────────────────
上传元数据 Excel      →    数据上传  →  数据清洗  →  匹配确认  →  数据导出
上传型号 Excel                                          ↓
                                                    查询工作台（发布后）
```

**准备工作**（初次使用时完成，后续有更新时维护）：
- 在「元数据管理」维护规格字段定义（决定导出 Excel 有哪些规格列）
- 在「型号管理」维护品牌型号信息（匹配的数据库）

**每批数据处理**（每次有新数据时执行）：
1. **数据上传** → 上传原始销售数据 Excel
2. **数据清洗** → 对上传数据去重、标准化，生成清洗任务
3. **匹配确认** → 自动匹配型号，人工处理未识别条目
4. **数据导出** → 生成带规格参数的 Excel 报告下载
5. **查询工作台** → 对已发布的数据进行查询分析

## 3. 数据上传

**入口**：左侧菜单 →「数据上传」

### 上传文件

1. 将原始销售数据 Excel 文件（`.xlsx` / `.xls`）拖拽到上传区域，或点击上传区域选择文件
2. 系统自动识别平台（京东 / 天猫 / 淘宝）和月份范围
3. 上传成功后，页面下方显示数据预览（前 50 行）

> **支持格式**：京东、天猫、淘宝原始数据导出格式，同一批次可上传多个平台的文件

### 上传历史

- 页面下方「上传历史」列表展示所有已上传文件
- 支持按文件删除（删除后对应原始数据也会一并删除）

## 4. 原始数据查看

**入口**：左侧菜单 →「原始数据」

用于浏览和核查已上传的原始数据，支持按以下条件筛选：

| 筛选项 | 说明 |
|--------|------|
| 平台 | 京东 / 天猫 / 淘宝 |
| 月份 | 如 202507 |
| 品牌 | 输入品牌名称关键词 |
| 关键词 | 宝贝名称模糊搜索 |

> 原始数据仅供查阅，所有处理操作在「数据清洗」中进行。

## 5. 元数据管理

**入口**：左侧菜单 →「元数据管理」

元数据定义了商品规格字段，例如「声道数」「输出功率」「连接方式」等，决定最终导出 Excel 中会出现哪些规格列。

### Excel 批量导入（推荐）

1. 点击右上角「Excel 导入」，选择元数据 Excel 文件
2. 系统弹出**预览确认窗口**，展示：
   - 读取行数 / 有效条目数
   - 错误列表（这些行会被跳过）
   - 警告列表
   - 前 10 条数据预览
3. 确认无误后点「确认导入」正式写入；点「取消」不产生任何修改

> **Excel 格式要求**：Sheet 名称必须为「元数据」，包含列：品类码、规格名称、规格类型（数值型/文本型/布尔型）、规格值（可选项，逗号分隔）、必填、单选

### 手动新增 / 编辑 / 删除

- 点击右上角「新增」可逐条添加
- 点击列表中每行的编辑（✏️）/ 删除（🗑️）图标操作

## 6. 型号管理

**入口**：左侧菜单 →「型号管理」

型号库是匹配的核心数据源，存放品牌所有在售 / 在管型号及其规格参数。

### Excel 批量导入（推荐）

1. 点击「Excel 导入」，选择型号 Excel 文件
2. 系统弹出**预览确认窗口**，展示：
   - 读取行数 / 有效型号数 / 规格行数
   - 错误和警告列表
   - 前 10 条型号预览
3. 确认无误后点「确认导入」

> **Excel 格式要求**：
> - Sheet「型号」：列包含 品牌码、型号码，以及可选的 品类、品牌名称、型号名称、上市年、上市月、上市周、上市价格、网址
> - Sheet「型号规格」：列包含 品牌码、型号码、规格名称、规格值
>
> 重复导入会自动更新，不产生重复记录（以 品牌码 + 型号码 为唯一键）

### 手动新增 / 编辑 / 删除

- 点击「新增型号」可手动添加，支持在表单中直接录入规格参数
- 点击列表行左侧「▶」箭头可展开查看该型号的规格明细
- 搜索框支持按品牌或型号码/名称过滤

## 7. 数据清洗

**入口**：左侧菜单 →「数据清洗」

清洗是对原始数据进行标准化处理，生成供后续匹配使用的干净数据集。

### 操作步骤

1. 在左侧「选择文件」中勾选一个或多个已上传的文件（可跨平台合并清洗）
2. 根据需要开启/关闭「去重」开关
   - **去重**：同一商品（相同 item_id）在同月份同店铺只保留第一条，避免重复计算
3. 点击「开始清洗」，等待完成（通常几秒内）
4. 清洗完成后在下方任务历史中可查看输入行数和输出行数

### 清洗任务历史

| 操作 | 说明 |
|------|------|
| 预览 | 查看该次清洗结果的数据详情 |
| 执行匹配 | 跳转到匹配确认页面，开始型号匹配 |

> 清洗结果独立保存，不影响原始数据，同一批文件可反复清洗。

## 8. 匹配确认

**入口**：左侧菜单 →「匹配确认」，或清洗任务历史中点「执行匹配」

将清洗后的商品数据与型号库进行匹配，识别出每条销售记录对应的品牌型号。

### 第一步：执行自动匹配

1. 在页面顶部「选择清洗任务」下拉框中选择一个清洗任务
2. 点击「执行匹配」按钮
3. 页面显示实时进度条（处理速度、预计剩余时间、已匹配条数）
4. 匹配完成后显示统计面板

### 匹配统计面板

| 指标 | 含义 |
|------|------|
| 总条数 | 该清洗任务的商品总数 |
| 自动匹配 | 系统自动识别出型号的数量 |
| 待确认 | 系统无法自动识别、需人工处理的数量 |
| 已人工确认 | 人工指定了型号的数量 |
| 已排除 | 确认不属于本次分析范围的数量 |
| 匹配率 | （自动匹配 + 已人工确认）/ 总条数 |

### 第二步：匹配复核规则说明（简洁版）

清洗任务详情页会按下面顺序展示 8 个复核队列。每个队列代表一种处理状态：

| 队列 | 是干嘛的 | 例子 | 处理方式 |
|------|----------|------|----------|
| 未识别品牌 | 有品牌线索，但系统还没确认到具体型号。 | 康佳电视显示原品牌/入库品牌为「康佳（KONKA）」，但当前型号是「未知」。 | 看链接和标题，确认型号后选择或新建型号；不确定就暂存争议。 |
| URL映射待确认 | 标题匹配到型号，但链接还没确认过。 | 同一商品链接第一次出现，系统还没有 URL 映射记录。 | 打开链接核对；正确就确认，错误就重选型号或排除。 |
| 待确认 | 系统有线索，但不能确定最终型号。 | 品牌能识别，但标题型号不清楚，或候选型号有多个。 | 查看标题、链接和候选型号；能判断就确认，不能判断就暂存争议。 |
| 争议复核 | 人工看过但暂时判断不了。 | 标题、图片、详情页不一致，或疑似套装/组合装。 | 写清争议原因；后续确认后再改为确认或排除。 |
| 已匹配 | 系统已自动匹配到型号。 | URL 映射、历史库、规则或算法已命中型号。 | 一般不用处理；发现错误时重新选择型号。 |
| 已人工确认 | 人工已经指定过型号。 | 分析师从待确认、未识别品牌等队列确认过。 | 一般不用处理；发现错误时重新选择型号。 |
| 已排除 | 人工确认不参与本次入库或分析。 | 非目标品类、无效商品、明显不属于当前任务。 | 一般不用处理；误排除时撤销后重新处理。 |
| 干扰项过滤 | 清洗阶段被规则过滤掉，不属于匹配结果。 | 命中低价、赠品、配件、无关关键词等规则。 | 检查过滤是否合理；误过滤就调整规则并重新清洗。 |

人工处理时只需要决定三件事：能确认型号就确认；暂时判断不了就暂存争议；不属于本次分析范围就排除。

### 第三步：发布到分析库

完成匹配后，点击「发布到分析库」将已匹配数据写入分析数据库，供「查询工作台」使用。

> 发布操作可执行多次，每次都会追加写入（建议确认匹配基本完成后再发布）。

## 9. 查询工作台

**入口**：左侧菜单 →「查询工作台」

> **前提**：已完成匹配并发布到分析库

用于对发布后的数据进行多维度查询，支持导出查询结果。

### 筛选条件

| 筛选项 | 说明 |
|--------|------|
| 月份 | 数据所属月份，如 202507 |
| 平台 | 京东 / 天猫 / 淘宝 |
| 品牌 | 标准品牌码 |
| 型号 | 标准型号码 |
| 品类 | 商品品类（Lv1） |
| 关键词 | 宝贝名称模糊搜索 |

### 操作说明

1. 设置好筛选条件后点「查询」
2. 结果表格展示：平台、月份、品牌、型号、品类、宝贝名称、销量、销售额等
3. 点「导出 Excel」可将当前筛选条件下的**全部**数据导出为 Excel 文件（不限页数）

## 10. 数据导出

**入口**：左侧菜单 →「数据导出」

将匹配结果导出为带规格参数的 Excel 报告，供外部使用。

> 与「查询工作台」导出的区别：此处导出的是**含规格参数列**的完整报告（宽表），按品类分 Sheet；查询工作台导出的是基础字段的明细表。

### 操作步骤

1. 在「选择清洗任务」中选择需要导出的任务
2. 在「文件名前缀」中输入报告名称（如「Soundbar 7-8月已处理」）
3. 右侧确认匹配状态（显示已匹配、已确认、待确认的数量）
4. 点击「提交导出任务」——系统立即提交，**无需等待**，页面下方任务列表会出现新记录
5. 等待任务状态变为「已完成」后，点击「下载」获取 Excel 文件

### 导出历史

| 状态 | 含义 |
|------|------|
| 排队中 | 任务已提交，等待处理 |
| 生成中 | 正在生成 Excel 文件 |
| 已完成 | 可点击「下载」 |
| 失败 | 鼠标悬浮「查看错误」可查看原因 |

> **导出文件结构**：
> - 每个品类一个 Sheet，Sheet 名为品类名称
> - 列包含：平台、月份、各类目、宝贝名称、销量、销售额、品牌、型号，以及「元数据管理」中定义的所有规格列
> - 如有待确认商品，会额外生成一个「待确认」Sheet（不含规格列）

## 11. 常见问题

**Q：上传后为什么数据量和文件实际行数不一样？**

A：系统会跳过表头、合计行等无效行，实际入库数量以页面提示为准。若有重复导入，会自动跳过重复记录。

---

**Q：执行匹配后匹配率很低怎么办？**

A：匹配率低通常有以下原因：
1. **型号库未导入目标品类数据** — 前往「型号管理」补充对应品类的型号
2. **品牌名称不统一** — 系统会尝试从宝贝名称中识别品牌码，但部分中文品牌名可能需要在型号库中完善 `brand_name` 字段
3. **数据本身不匹配** — 部分数据属于目标品类范围之外，可在「匹配确认」中选择「排除」

---

**Q：元数据 / 型号导入时提示格式错误怎么办？**

A：点击「Excel 导入」后会显示预览弹窗，其中「错误」折叠面板会精确指出哪一行有问题。常见原因：
- 元数据：缺少「规格名称」或「规格类型」列
- 型号：缺少「品牌码」（或「品牌」）和「型号码」（或「型号」）列
- Sheet 名称拼写不对（元数据 Sheet 名须为「元数据」，型号须为「型号」和「型号规格」）

---

**Q：导出的 Excel 里规格列全是空的？**

A：检查「元数据管理」中是否已导入规格定义。规格列的名称来自元数据，若元数据为空则导出文件没有规格列。

---

**Q：发布后查询工作台看不到数据？**

A：确认以下步骤都已完成：
1. 执行匹配（匹配率 > 0）
2. 在「匹配确认」页面点击「发布到分析库」，等待发布成功提示
3. 回到「查询工作台」，点「查询」按钮（首次进入不会自动加载数据）

---

**Q：数据导出任务一直显示「排队中」？**

A：可点右上角「刷新」手动刷新状态。若长时间未变化，可联系管理员检查服务状态。
