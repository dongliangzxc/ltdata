# 数据上传提示与同名原件隔离（2026-11-23）

用户确认修复同名上传覆盖历史原件，并要求数据质量只做提示，点击确认仍可上传。2026-11-23 用户进一步要求“先上线吧”，本次发布包含上述功能及 24 个合成测试文件，不纳入个人数据附件和导出目录。

## 行为

- 同步和异步上传为每份原件生成唯一存储名，保存到 `UPLOAD_DIR/originals/`。页面与附件继续使用原文件名。直接下载、后台下载和批次打包均按上传记录定位文件。
- 旧记录的存储引用为空，继续使用旧路径；新原件缺失时不误取旧版同名文件。已经被覆盖的历史内容需要从备份恢复。
- 单文件和批量确认入库前，按当前列映射检查全部数据。提示空必填值、异常数字、非法月份，展示行号、原始值、原因、完整统计，每文件最多显示 50 处示例。
- “返回检查”不创建入库任务，保留待处理文件；“仍然上传”继续。批量在任何文件入库前集中提示。无问题不弹窗。
- 缺失值和无法保存的数字留空，不猜测、不截断或补 0。非法整数月份允许保留，提示其对月份查询的影响。只读检查接口不写入商品数据或创建任务。
